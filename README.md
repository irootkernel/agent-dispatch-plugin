# Agent Dispatch Plugin

agent-dispatch-plugin is a planned standalone Hermes plugin that exposes a
small, typed, inspection-only view of Agent Dispatch. Version 0.1.0 is designed
around ten fixed tool contracts, one hardened process boundary, and explicit
compatibility evidence.

No plugin runtime is implemented yet. The current repository authority is:

- Product requirements: docs/specs/PRD.md
- Initial roadmap: docs/roadmap/README.md
- Maintainer documentation index: docs/README.md
- Hermes proposal: docs/agent-dispatch-plugin.md, retained as non-canonical
  working input

The project targets a public MIT-licensed repository at
github.com/irootkernel/agent-dispatch-plugin. Installation, activation,
publishing, and release work are outside the current design phase.
