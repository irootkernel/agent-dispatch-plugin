# Architecture Decision Records

This directory records durable technical choices that implement the PRD
without changing it.

Use ADR-NNN-short-title.md with status, context, decision, consequences,
alternatives, and verification. Allowed statuses are Proposed, Accepted,
Superseded, and Rejected. A superseding ADR links the record it replaces.

No ADRs are accepted at project initialization. Candidate decisions are listed
in adopted TODO dossiers and must not weaken product contracts.
